# Wow Kalyanam (వౌ కల్యాణం) · Luxury Digital Wedding Invitations

An interactive, responsive digital wedding invitation platform featuring curated royal themes, dynamic guest link generation, ambient audio, and password-protected preview access.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/wowkalyanam/weddinginvitation.git

# Navigate to project folder
cd weddinginvitation

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
```
